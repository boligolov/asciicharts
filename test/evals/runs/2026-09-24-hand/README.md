# Hand-drawn eval run, 2026-09-24

The raw replies of the run summarised in `../../README.md` (*Hand-drawn results*): seven prompts from
`hand_evals.json`, each answered once with the skill (`with_skill/`) and once without it
(`without_skill/`), by independent agents that were not allowed to run code. `reply.md` is the reply
exactly as the agent saved it; `grading.json` is what `hand_grade.py` made of it.

Kept on purpose, not just for the numbers: the replies are a catalogue of how agents lay out text charts
on their own — value axes, values over columns, `◄ ►` direction headers, axis ticks under bars, `░` as
a second series, a true hand-computed pie — material for the principles and the drawing guide.
